# furniture_portfolio_2

> **MAISON NOIR** — Luxury High-Contrast Salon & Haute Furniture Experience.

A theatrical, high-contrast dark luxury furniture experience featuring dramatic spotlighting, 360° interactive turntable product inspection, and bespoke material customization.

## 🚀 Key Features
- **Theatrical Presentation**: High-contrast noir aesthetic with dynamic directional lighting
- **Interactive 360° Inspection**: Full orbit 3D product view with real-time material switching
- **Production HTML & Bundle**: Pre-compiled production build included in `dist/`

## 🛠 Tech Stack
- **React 18** + **Vite**
- **Three.js** / WebGL
- **GSAP** Motion Design
- **Tailwind CSS**

## 💻 Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
